# Cross Fix

Keiki Play, Cross Fix, and Surf-Fix.

## Run

Requires Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm start
```

Use Import JSON and Export JSON in the game to load or download a board. Games remain in memory; refreshing or closing the page clears the board. Sound and timer preferences are remembered on this device.
